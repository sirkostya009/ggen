# gen — cross-language export for ggen types

Library, not CLI. User write small Go script: load packages, pick types, place shapes into files, call `Write`. Emitters receive plain data, write every character themselves. Core has no opinion about target syntax.

Module: `github.com/sirkostya009/ggen/gen`. Go ≥ 1.27. Independent of runtime package — script never import `github.com/sirkostya009/ggen`.

Ships five emitters: `ts` (TypeScript types), `zod` (Zod 4), `valibot` (Valibot 1.x), `kotlin` (kotlinx.serialization), `swift` (Codable).

## When to reach for gen

Use when ANY hold:

- Frontend/mobile need types or runtime validation matching Go structs, and Go is source of truth.
- Hand-maintained schema duplicate already drifted from Go once.
- Target language not shipped — write emitter against `gen.Emitter`, reuse parser + lowering.

Skip when:

- User want OpenAPI/JSON Schema out of HTTP handlers. gen describe TYPES, not routes. (JSON Schema emitter writable in ~100 lines, none shipped.)
- Types not ggen-annotated. gen read `//ggen:generate` structs plus what they reach.

## Install

```sh
go get github.com/sirkostya009/ggen/gen
```

Put script under its own directory, run with `go run ./cmd/schemas`. Nothing generate it for you; no `//go:generate` convention imposed.

## Minimal script

```go
package main

import (
	"log"

	"github.com/sirkostya009/ggen/gen"
	"github.com/sirkostya009/ggen/gen/ts"
	"github.com/sirkostya009/ggen/gen/zod"
)

func main() {
	set, err := gen.Load("./internal/api/...")
	if err != nil {
		log.Fatal(err)
	}

	out := gen.NewOutput("web/src/schemas")
	header := "// Code generated by ggen. DO NOT EDIT."
	helpers := out.File("ggen.ts", ts.Runtime(header))
	e := zod.New(zod.Runtime(helpers), zod.ImportExt(".ts"), zod.Header(header))

	requests, responses := out.File("requests.ts", e), out.File("responses.ts", e)
	for _, t := range set.Types() {
		if t.Has("schema:in") {
			requests.Place(t.In(), t.Name)
		}
		if t.Has("schema:out") {
			responses.Place(t.Out(), t.Name)
		}
	}

	if err := out.Write(); err != nil {
		log.Fatal(err)
	}
	for _, i := range out.Report().Issues {
		log.Println("not expressible:", i) // never silent
	}
}
```

Four steps, always: **load → shape → place → write**.

## Step 1: load

```go
set, err := gen.Load("./internal/api", "./internal/shared/...")
```

Patterns are directories or `...` patterns relative to working directory. Test-file types skipped.

| call                         | gives                                                                        |
| ---------------------------- | ---------------------------------------------------------------------------- |
| `set.Packages`               | loaded packages, dependency order                                            |
| `set.Types()`                | every generated type of every loaded package                                 |
| `set.Package(importPath)`    | one loaded package, or nil                                                   |
| `set.Type(importPath, name)` | one type by path + name                                                      |
| `set.Enums()`                | enum types the loaded types reference (named string/int + constants)         |
| `set.Unloaded()`             | ggen types reached in packages no pattern matched — load them for full shape |

`TypeDecl` carry `Pkg`, `Name`, `Doc`, `File`, `Directives`, `Annotated`, `Enum`. `t.Has("schema:in")` test one `//schema:in` line. Directives are how script route types without hardcoding names.

## Step 2: shape

`t.In()` = what generated DECODER accepts. `t.Out()` = what generated ENCODER emits. Different objects, never interchangeable:

|                  | input                                    | output                                    |
| ---------------- | ---------------------------------------- | ----------------------------------------- |
| `Field.Optional` | key may be absent (no `required`)        | encoder may omit (`omitempty`/`omitzero`) |
| `Type.Nullable`  | null accepted                            | null can be emitted                       |
| `Type.Rules`     | validation + transforms, declared order  | always empty                              |
| `Type.OneOf`     | extra shapes a `@Conv` converter accepts | empty                                     |
| `Enum.Zero`      | false                                    | true when Go zero value not a constant    |

`Shape`: `Decl`, `Mode`, `Fields` (struct) or `Alias` (alias/enum type), `Recursive`, `Unknown` + `Rest`, `Field(jsonName)`.

`Field`: `GoName`, `JSONName`, `Doc`, `Directives`, `Type`, `Optional`.

`Type` is the workhorse:

| field                           | meaning                                                                                                                                                                                                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Go`                            | Go kind: `String`, `Int8`…`Uint64`, `Float32/64`, `Time`, `Duration`, `Bytes`, `IP`, `Addr`, `Prefix`, `URL`, `BigInt`, `BigFloat`, `BigRat`, `RawJSON`, `Number`, `Slice`, `Array`, `Map`, `Struct`, `Any`                                                              |
| `Wire`                          | JSON shape: `WireString`, `WireInteger`, `WireNumber`, `WireBool`, `WireArray`, `WireObject`, `WireAny`                                                                                                                                                                  |
| `Format`                        | `date-time`, `unix`, `unixmilli/micro/nano`, `duration`, `duration-sec/milli/micro/nano`, `base64`, `base64url`, `base32`, `base32hex`, `hex`, `ip`, `ip-zone`, `cidr`, `uri`, `int-string`, `uint-string`, `number-string`, `big-float`, `rational`, `time:<Go layout>` |
| `Elem`, `Key`, `Len`            | slice/array/map parts; `Len` also the decoded length of `[N]byte`                                                                                                                                                                                                        |
| `Ref`                           | points at another generated type, or an enum type                                                                                                                                                                                                                        |
| `External`                      | named type ggen does not generate; identify by `Pkg.Path + "." + Name`                                                                                                                                                                                                   |
| `Enum`                          | closed set of values (`Values[i].Value` is JSON literal, `.Text` the decoded string, `.Name` the Go constant)                                                                                                                                                            |
| `Rules`, `OneOf`, `Converted`   | validation, converter inputs, "rules describe converted value"                                                                                                                                                                                                           |
| `Nullable`, `Empty`             | null accepted/emitted; `""` accepted/emitted for IP, Addr, Prefix, URL                                                                                                                                                                                                   |
| `GoType`, `Name`, `Pkg`, `File` | Go spelling and origin, for error messages and mappings                                                                                                                                                                                                                  |

`Rule`: `Op` (`MinLen`, `GTE`, `OneOf`, `Trim`, `ToLower`, `Replace`, `Clamp`, `Func`, …), `Args`, `Transform` (changes value vs checks it), and for `Op == Func`: `Func`, `FuncPkg`, `Msg`.

Object policy for undeclared keys is `Shape.Unknown`: `Reject`, `Ignore`, or `Collect` (then `Shape.Rest` is the `json:",embed"` map's value type).

Tighten a shape when the script knows more than the decoder:

```go
responses.Place(set.Type(api, "User").Out().StrictFields("role"), "User")
// Strict() = every field, every depth: no null, no zero widening, no "" for IP-likes.
```

## Step 3: place

```go
f := out.File("web/requests.ts", emitter) // same path + same emitter returns same file
f.Place(shape, "CreateUser").Place(other, "Address")
```

Placement name is what the target calls the type. Nothing renamed silently: name not valid in target fails `Write`.

## Step 4: write

`out.Write()` validates whole graph BEFORE writing any byte, then writes all files or none. Fails on:

- reference to a shape not placed in this output,
- same type placed twice in one mode, or one name used by two shapes in a file,
- one file requested with two different emitters,
- reference cycle whose members are not all in one file,
- a type `Set.Type` never loaded.

Ordering handled for you: within a file, a shape follows shapes it references; a genuine cycle keeps placement order and `ctx.Later(...)` tells the emitter the reference points forward.

`out.Report().Issues` collect what an emitter could not express (unmapped external type, rule with no twin, catch-all in a language without one). Report is not an error — print it, or fail your build on it.

## Emitters

Every option that decides something has a `…For` twin taking a function, so one emitter serve many files: `func(f *gen.File, p gen.Placed) T` per type, `func(f *gen.File) T` per file. `p.Shape.Decl` carry package, file, name and directives, so decisions can follow layout or annotation.

### ts — TypeScript types

`ts.New(opts...)`. Interfaces + type aliases, no runtime code, rules dropped.

| option                                     | effect                                              |
| ------------------------------------------ | --------------------------------------------------- |
| `Header(line)` / `HeaderFor`               | first line of file                                  |
| `ImportExt(".ts")`                         | extension on import specifiers                      |
| `Indent("  ")`                             | indentation                                         |
| `TypeAliases()` / `TypeAliasesFor`         | `type X = {…}` instead of `interface X`             |
| `External(goPath, tsType)` / `ExternalFor` | render a foreign type                               |
| `ts.Runtime(header)`                       | emitter for shared helpers file used by zod/valibot |

### zod — Zod 4, and valibot — Valibot 1.x

Same option set, same declaration shape. `zod.New(opts...)` emit `export const X = …` + `export type X = z.output<typeof X>`; valibot emit head schema + pipe actions and `v.InferOutput`.

| option                                     | effect                                                                                                      |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| `Header` / `HeaderFor`, `ImportExt`        | as in `ts`                                                                                                  |
| `Runtime(file)`                            | import helpers from a shared `ts.Runtime` file instead of inlining them                                     |
| `External(goPath, schema)` / `ExternalFor` | schema for a foreign type                                                                                   |
| `ExternalType(goPath, tsType)`             | its TypeScript annotation (default `unknown`)                                                               |
| `Func(ref, action)` / `FuncFor`            | twin for a `@Func` validator: `zod.Func("IsAdult", ".refine((x) => x >= 18)")`, valibot takes a pipe action |
| `SchemaName(fn)`                           | name of the exported constant                                                                               |
| `Override(fn)`                             | render any type yourself (bigint, branded types)                                                            |

Built-ins used only where probing showed they match Go; everything else comes from generated helpers that port the Go parser (time layouts, `big.Float`, `big.Rat`, `url.Parse`, IP/CIDR, durations, `,string` grammars). Unmapped `@Func` and unmapped external types are reported, not guessed.

### kotlin — kotlinx.serialization

`kotlin.New("com.example.api", opts...)`. Data classes, types only.

| option                                               | effect                                                     |
| ---------------------------------------------------- | ---------------------------------------------------------- |
| `Header` / `HeaderFor`                               | first line                                                 |
| `IgnoreUnknown()`                                    | `@JsonIgnoreUnknownKeys` everywhere, whatever Go does      |
| `External(goPath, type, imports...)`                 | foreign type + imports                                     |
| `ExternalWith(goPath, type, annotation, imports...)` | same, plus `@Contextual` or a custom serializer annotation |
| `ExternalFor(fn)`                                    | per use                                                    |

kotlinx fails on an absent key unless the property has a default, so an optional field gets Go's zero value as default. String enum types become `enum class`; integer enum types cannot exist in kotlinx and are reported.

### swift — Codable

`swift.New("API", opts...)`, plus `swift.NewRuntime("API")` for the file holding `JSONValue` and `Indirect`.

| option                                                    | effect                                                                       |
| --------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `Header` / `HeaderFor`                                    | first line                                                                   |
| `Runtime(file)`                                           | where `JSONValue` / `Indirect` live; without it every use is reported        |
| `Protocols("Hashable", "Sendable")` / `ProtocolsFor`      | conformances beyond `Codable` (default `Hashable`)                           |
| `Public()` / `PublicFor`                                  | public types + memberwise `init`                                             |
| `Indirect(name)` / `IndirectFor`                          | property wrapper for recursion; `Indirect("")` renders `final class` instead |
| `External(goPath, swiftType, modules...)` / `ExternalFor` | foreign type + imports                                                       |

A synthesized `init(from:)` fails on an absent key unless the property is Optional, so optional and nullable fields are `T?`. Encoding leaves a nil property out, which Go reads as the zero value.

## Writing your own emitter

```go
type Emitter interface {
	Begin(ctx *gen.Context) error            // reset per file
	Decl(ctx *gen.Context, p gen.Placed) error // once per placed shape, in order
	End(ctx *gen.Context) error              // flush into ctx.W
}
```

`ctx.W` take `Header(line)`, `Import(line)` (deduplicated), `Printf`, `WriteString`; header lines, then imports, then body. `ctx.File.Placed()` list every name of this file up front. For a reference: `ctx.Lookup/Resolve(ref, mode)` give its placement, `ctx.FileOf` its file, `ctx.Rel(file)` the relative path from here, `ctx.Later` whether it points forward, `ctx.Cyclic` whether it sits on a cycle with another type. Anything you cannot express goes to `ctx.Report.Add(where, msg)`.

Returning an error from any method aborts the whole write, so nothing half-written lands.

## Pitfalls

- **Enum closed set is an assertion, not a decoder fact.** Generated Go decoder accept any value of the underlying type; the schema rejects. Same class as `Strict()`. Deliberate.
- **`Set.Unloaded()` is not noise.** A ggen type in an unloaded package lower as external with no fields. Load its package.
- **Input and output differ.** Placing `t.In()` where you meant `t.Out()` compiles and produces wrong schema. Name the placements accordingly (`CreateUser` vs `CreateUserInput`).
- **A catch-all (`json:",embed"`) types as `X & Record<string, Rest>` in TypeScript**, so declared fields must fit `Rest` too. Kotlin and Swift have no catch-all at all and report it.
- **Micro/nanosecond Unix times do not fit JavaScript numbers.** zod/valibot assert integer-ness only and report it.
- **Swift and Kotlin leave a nil property out when encoding.** Go reads absent as zero, so round trips agree, but bytes differ from Go's `null`.
- **Rules are input-only.** Nothing in `t.Out()` carry validation; do not expect output schemas to police values.

## Verifying output

Emitted schema must agree with generated decoder, not merely look right. Three checks, cheapest first:

1. **Fail the build on a non-empty `Report`.** Every issue is a rule or type the emitter dropped. Allow-list the ones you accept, by string, so a new one break the build.
2. **Compile what you emit**, in the script's own test: `tsc --strict` over the TypeScript, `kotlinc` over the Kotlin, `swiftc` over the Swift. Catch name collisions, keyword clashes, missing imports.
3. **Differential probe.** Take a list of JSON values, feed each through BOTH the generated Go decoder and the emitted schema, assert same accept/reject verdict, and for what both accept assert Go read the same value out of what the schema parsed. Keep allowed divergences as explicit predicates with a reason each, and fail when a predicate stop explaining any disagreement — a stale exception is how a real regression hide.

Probe list worth having: type boundaries (`127`/`128`, `2147483648`, `9007199254740993`), spellings JavaScript cannot distinguish (`1.0`, `-0`, `1e2`), `1e400` and `1e-400`, `null`, `""`, `[]`, `{}`, every enum member plus one non-member, escapes and non-ASCII text, and one value per rule that sit just inside and just outside the bound.
